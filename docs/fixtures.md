# Fixture provenance rules

Status: required delivery policy
Last updated: 2026-09-03

This document turns the fixture rules in `docs/evaluation.md` §5 into a
concrete contract for every fixture committed to this repository. It applies
to PDF/EPUB samples, diagram images, FEN/PGN sets, UCI logs, and any other
input consumed by a test or `eval:*` suite.

## 1. Allowed sources

A fixture may be:

- **synthetic** — generated in-repo by a committed generator script (a
  script that produces the exact bytes deterministically, not a one-off
  external tool run once and only the output kept); or
- **public-domain** — verifiably out of copyright, with the source recorded;
  or
- **explicitly redistributable** — carries a license that permits
  redistribution in this repository (e.g. CC0, CC-BY with attribution
  carried in the manifest, or a license the asset's own author grants for
  this kind of reuse).

## 2. Forbidden

- Any user-owned copyrighted book, in whole or in part (including a single
  page or diagram crop).
- A screenshot or photograph of a copyrighted book, even a small excerpt.
- An unlicensed image pulled from the web "because it looked right."
- Anything whose license or provenance cannot be stated in the manifest.

When a bug is found against real copyrighted content, reduce it to a
synthetic equivalent that reproduces the failure (matching layout/diagram
style, not the original text/images) whenever that is legally and practically
possible; see §6.

## 3. Size limits

- 5 MB per individual fixture file.
- 50 MB total committed under `packages/test-fixtures/`.
- A fixture that would exceed either limit is generated by a committed
  generator at test/eval time instead of being committed as bytes, or is
  kept out of the repository entirely (see §7, `fixtures-local/`).

## 4. Location and naming

- Fixtures live under `packages/test-fixtures/`, created by the first issue
  that actually needs one (issue #2, per `docs/issue-plan.md`). **Do not
  create that package now** — this document defines the contract it must
  follow once it exists.
- File names are stable, lower-kebab-case, and describe content plus variant,
  not an incrementing number: e.g. `pdf-scanned-rotated-90.pdf`,
  `diagram-hatched-grayscale-01.png`, `perft-kiwipete.json`.
- Every fixture file has a corresponding entry in `manifest.json` keyed by a
  stable `id`; nothing under `packages/test-fixtures/` is untracked by the
  manifest.

## 5. `manifest.json` schema

The manifest is validated against this JSON Schema (2020-12):

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "$id": "https://chess-reader.local/schemas/fixture-manifest.json",
  "title": "Fixture manifest",
  "type": "object",
  "required": ["schemaVersion", "fixtures"],
  "additionalProperties": false,
  "properties": {
    "schemaVersion": { "const": 1 },
    "fixtures": {
      "type": "array",
      "items": { "$ref": "#/$defs/fixture" }
    }
  },
  "$defs": {
    "fixture": {
      "type": "object",
      "required": [
        "id",
        "sha256",
        "path",
        "contentType",
        "source",
        "tags",
        "expected",
        "tolerance",
        "limitations",
        "consumers",
        "addedInIssue"
      ],
      "additionalProperties": false,
      "properties": {
        "id": { "type": "string", "pattern": "^[a-z0-9]+(-[a-z0-9]+)*$" },
        "sha256": { "type": "string", "pattern": "^[0-9a-f]{64}$" },
        "path": { "type": "string", "minLength": 1 },
        "contentType": {
          "type": "string",
          "enum": [
            "application/pdf",
            "application/epub+zip",
            "image/png",
            "image/jpeg",
            "application/json"
          ]
        },
        "source": {
          "type": "object",
          "required": ["kind", "license", "retrieved"],
          "additionalProperties": false,
          "properties": {
            "kind": { "type": "string", "enum": ["synthetic", "public-domain", "licensed"] },
            "generator": { "type": "string", "minLength": 1 },
            "url": { "type": "string", "format": "uri" },
            "license": { "type": "string", "minLength": 1 },
            "retrieved": { "type": "string", "format": "date" }
          },
          "oneOf": [{ "required": ["generator"] }, { "required": ["url"] }]
        },
        "tags": {
          "type": "array",
          "items": { "type": "string" },
          "minItems": 1
        },
        "expected": {
          "type": "object",
          "description": "Locators/rectangles/FEN/orientation as applicable to this fixture's consumers.",
          "additionalProperties": true
        },
        "tolerance": {
          "type": "object",
          "description": "Allowed deviation, e.g. rectangle IoU or pixel tolerance; empty object if exact-match.",
          "additionalProperties": true
        },
        "limitations": {
          "type": "array",
          "items": { "type": "string" }
        },
        "consumers": {
          "type": "array",
          "items": { "type": "string" },
          "minItems": 1,
          "description": "Eval suite names (e.g. eval:reader, eval:recognition) or test files that use this fixture."
        },
        "addedInIssue": { "type": "integer", "minimum": 1 }
      }
    }
  }
}
```

### Example entry

```json
{
  "id": "pdf-scanned-rotated-90",
  "sha256": "9f2c1a4e7b3d5f608e1c2a4b6d8f0a1c3e5f7091b3d5f7091b3d5f7091b3d5f",
  "path": "pdf/pdf-scanned-rotated-90.pdf",
  "contentType": "application/pdf",
  "source": {
    "kind": "synthetic",
    "generator": "generators/make-scanned-pdf.mjs --rotate=90",
    "license": "CC0-1.0",
    "retrieved": "2026-09-03"
  },
  "tags": ["pdf", "scanned", "rotated", "single-diagram"],
  "expected": {
    "locator": { "page": 0 },
    "rectangles": [{ "x": 0.12, "y": 0.2, "width": 0.5, "height": 0.5 }],
    "orientation": "white-bottom"
  },
  "tolerance": {
    "rectangleIou": 0.9
  },
  "limitations": ["Single synthetic diagram style; does not cover hand-drawn boards."],
  "consumers": ["eval:reader"],
  "addedInIssue": 2
}
```

Every field in `expected` and `tolerance` is suite-specific — a chess fixture
records FEN/perft counts instead of rectangles, an engine fixture records
UCI output instead of either. Keep them as plain, documented JSON rather than
inventing a second schema per suite.

## 6. Bug-fix rule

Per `AGENTS.md` and `docs/evaluation.md` §2, a bug fix adds a minimized
regression fixture whenever the triggering input can be legally committed:

- reduce the input to the smallest synthetic reproduction of the failure;
- add it to `manifest.json` with `tags` including `regression` and a
  `limitations` note pointing at the issue/PR that found it;
- if the triggering input cannot be legally reduced and committed (e.g. it
  only reproduces against a real copyrighted book), say so explicitly in the
  PR instead of committing the original bytes or skipping the regression
  test.

## 7. Local ignored corpus

A contributor's own copyrighted books, or any fixture candidate that is
still being triaged, belongs in `fixtures-local/` at the repository root —
**never** under `packages/test-fixtures/`. `fixtures-local/` is listed in
`.gitignore` and must never be committed. Suites must treat fixtures under
`fixtures-local/` as optional/skippable local input, not as part of the
required, checked-in corpus that CI depends on.
